# FixCase - Gestión de Equipos y Tickets

Sistema de gestión de tickets y mantenimiento de equipos desarrollado para optimizar el seguimiento de solicitudes e incidencias.

## 🛠️ Tecnologías Utilizadas

- **Backend:** Python (Flask, SQLAlchemy, PyJWT)
- **Frontend:** HTML5, CSS3, JavaScript (Módulos ES6)
- **Base de Datos:** MySQL / SQL Server
